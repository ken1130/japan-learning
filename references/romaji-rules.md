# 羅馬拼音規則（本專案統一用法）

採**修正平文式（Hepburn）**為主，長音照假名寫，方便初學者對照假名。

## 基本

| 假名 | 拼音 | 注意 |
|---|---|---|
| し シ | shi | 不寫 si |
| ち チ | chi | 不寫 ti |
| つ ツ | tsu | 不寫 tu |
| ふ フ | fu | 不寫 hu |
| じ ぢ | ji | ぢ 很少見 |
| ず づ | zu | づ 很少見 |
| を ヲ | o | 發音同 お |
| ん ン | n | |
| しゃ しゅ しょ | sha shu sho | |
| ちゃ ちゅ ちょ | cha chu cho | |
| じゃ じゅ じょ | ja ju jo | |

## 助詞

助詞照**發音**寫：

| 寫法 | 拼音 | 例 |
|---|---|---|
| は（助詞） | wa | トイレ**は**どこですか → toire **wa** doko desu ka |
| を | o | 水**を**ください → mizu **o** kudasai |
| へ（助詞） | e | 駅**へ** → eki **e** |

## 長音

照假名直接寫，不用 ō / ū 這類符號：

| 例 | 拼音 |
|---|---|
| ありがとう | arigat**ou** |
| せんせい | sens**ei** |
| おおきい | **oo**kii |
| ラーメン（ー） | r**aa**men |
| コーヒー | k**oo**h**ii** |

## 促音（小っ）

重複下一個子音；`ch` 前面加 `t`：

| 例 | 拼音 |
|---|---|
| きっぷ | ki**pp**u |
| ちょっと | cho**tt**o |
| まっちゃ | ma**tch**a |

## 分詞

句子在「詞」與「助詞」之間加空格：`nihongo ga wakarimasen`。
`です／ます` 前通常空一格：`ikura desu ka`。

## 自動轉換

單字的拼音由 `js/data/kana.js` 的 `kanaToRomaji()` 從假名自動產生；會話句因為有助詞，**手動填 `ro` 欄位**。
假名雨遊戲另外接受訓令式拼法（si、ti、tu、hu…），因為輸入法常這樣打。
