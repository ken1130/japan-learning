# 菜單詞彙速查

網站的完整資料在 `js/data/food.js`，這裡是出門可以印的精簡版與「讀菜名的技巧」。

## 讀菜名的技巧：拆開來看

日文菜名通常是「**食材 + 作法 + 料理種類**」的組合：

| 菜名 | 拆解 | 意思 |
|---|---|---|
| 鶏の唐揚げ | 鶏（雞）+ の + 唐揚げ（炸） | 炸雞 |
| えび天ぷら | えび（蝦）+ 天ぷら | 炸蝦天婦羅 |
| 豚骨ラーメン | 豚骨 + ラーメン | 豬骨拉麵 |
| 牛丼 | 牛 + 丼（蓋飯） | 牛肉蓋飯 |
| 焼き魚定食 | 焼き（烤）+ 魚 + 定食（套餐） | 烤魚套餐 |

| 漢字 | 讀音 | 意思 |

| 牛 | ぎゅう | 牛 |

| 鶏 | とり | 雞 |
| 魚 | さかな | 魚 |
| 卵／玉子 | たまご | 蛋 |
| 丼 | どん | 蓋飯 |
| 焼 | や（き） | 烤、煎 |
| 揚 | あ（げ） | 炸 |
| 煮 | に | 燉 |

## 價格標示

| 標示 | 意思 |
|---|---|
| 税込 | 含稅（實際付這個） |
| 税抜／本体価格 | 未稅，結帳會再加 8%～10% |
| 〜円 | 日圓 |
| 無料 | 免費 |
| おかわり自由 | 免費續（飯、飲料） |
| 時価 | 時價（壽司店常見） |

## 店家特有

| 用語 | 說明 |
|---|---|
| 券売機 | 先買餐券再入座（拉麵、牛丼店） |
| お通し | 居酒屋的入座小菜，會自動收費 |
| 食べ放題／飲み放題 | 吃到飽／喝到飽，通常有時間限制 |
| ラストオーダー（L.O.） | 最後點餐時間 |
| 替え玉 | 只加麵（博多拉麵） |
