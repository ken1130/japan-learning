# 假名字源表

平假名來自漢字的**草書**，片假名多取漢字的**一部分（偏旁）**。
對懂中文的人來說，先知道字源，記假名會快很多。

## 容易混淆

| 組合 | 分辨方法 |
|---|---|
| さ / ち | 方向相反：さ 開口向左下，ち 開口向右 |
| ぬ / め | ぬ 尾巴多一個圈 |
| ね / れ / わ | 看右下：ね 有圈、れ 往外翹、わ 往內收 |
| る / ろ | る 有圈 |
| シ / ツ | シ 的點橫排、筆畫由下往上；ツ 的點直排、筆畫由上往下 |
| ソ / ン | ソ 兩筆都偏直；ン 第一筆偏橫、第二筆由下往上 |
| ク / ケ / タ | ケ 的橫穿出去；タ 中間多一點 |
| コ / ユ | ユ 底下橫線較長 |
