# 旅遊用的最小文法

不用學完整文法，掌握這幾個「句型模板」，換掉名詞就能講很多話。

## 1. 〇〇をください — 請給我〇〇

| 句子 | 意思 |
|---|---|
| これ**をください** | 請給我這個 |
| 水**をください** | 請給我水 |
| メニュー**をください** | 請給我菜單 |
| これを二つ**ください** | 請給我兩個這個 |

## 2. 〇〇はどこですか — 〇〇在哪裡？

| 句子 | 意思 |
|---|---|
| トイレ**はどこですか** | 廁所在哪？ |
| 駅**はどこですか** | 車站在哪？ |
| コインロッカー**はどこですか** | 置物櫃在哪？ |

## 3. 〇〇はありますか — 有〇〇嗎？

| 句子 | 意思 |
|---|---|
| 英語のメニュー**はありますか** | 有英文菜單嗎？ |
| 大きいサイズ**はありますか** | 有大尺寸嗎？ |
| Wi-Fi**はありますか** | 有 Wi-Fi 嗎？ |

## 4. 〇〇できますか／〇〇は使えますか — 可以〇〇嗎？

| 句子 | 意思 |
|---|---|
| 免税**できますか** | 可以免稅嗎？ |
| カード**は使えますか** | 可以刷卡嗎？ |
| 試着してもいいですか | 可以試穿嗎？ |

## 5. 〇〇まで（お願いします） — 到〇〇

| 句子 | 意思 |
|---|---|
| 新宿**まで**いくらですか | 到新宿多少錢？ |
| このホテル**まで**お願いします | 請載我到這間飯店（計程車） |

## 6. 〇〇が〜です — 描述狀態

| 句子 | 意思 |
|---|---|
| 頭**が**痛いです | 頭痛 |
| おなか**が**痛いです | 肚子痛 |
| 気分**が**悪いです | 不舒服 |

## 句尾

- **〜です**：是〜（禮貌）
- **〜か**：加在句尾變問句（語調上揚）
- **〜ます／〜ません**：動詞的肯定／否定（禮貌）

## 敬語：聽懂就好

店員會對你用敬語，句子很長，但抓關鍵字就懂：

| 店員說 | 關鍵字 | 意思 |
|---|---|---|
| ご注文は**お決まり**ですか | 決まり（決定） | 決定好要點什麼了嗎？ |
| 店内で**お召し上がり**ですか | 店内（店裡） | 內用嗎？ |
| **袋**はご利用ですか | 袋（袋子） | 需要袋子嗎？ |
| **温め**ますか | 温め（加熱） | 要加熱嗎？ |
| 少々**お待ち**ください | 待ち（等） | 請稍等 |
