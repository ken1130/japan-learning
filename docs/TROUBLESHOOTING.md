# 疑難排解

## 沒有聲音

1. **改用 Microsoft Edge**：Edge 內建高品質日文語音（Nanami / Keita），最推薦。
2. Chrome 有「Google 日本語」語音，但需要網路。
3. Windows 新增日文語音：設定 → 時間與語言 → 語音 → 新增語音 → 日本語。新增後重開瀏覽器。
4. 點右上角 ⚙，下方會顯示「目前語音」。若顯示找不到日文語音，就是系統沒裝。

## 畫面一片白／功能都不能用

- 確認是用 `start.bat` 開的 `http://localhost:8000`，而不是直接雙擊 `index.html`（`file://` 會擋 ES modules）。
- 第一次開需要網路下載 three.js 與字型。

## 3D 動畫沒出現

- 瀏覽器需支援 WebGL。在網址列輸入 `chrome://gpu` 或 `edge://gpu` 檢查。
- 3D 場景是輔助，沒有 WebGL 時其他功能照常可用。

## 8000 port 被占用

編輯 `start.bat`，把兩處 `8000` 改成 `8080` 之類的數字。

## 想重設進度

首頁最下方「重設學習進度」。設定（語速、主題）會保留。
