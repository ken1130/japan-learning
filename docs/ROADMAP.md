# 未來可以加的功能

依「對旅行幫助多寡」排序，想做哪個跟 Claude 說即可。

## 內容

- [ ] 更多情境：溫泉／錢湯規則、藥妝店、問路（右、左、直走）、天氣
- [ ] 更多模擬菜單：壽司店（迴轉壽司點餐平板）、咖啡廳、便利商店貨架
- [ ] 車站情境：JR 售票機畫面模擬、轉乘路線圖
- [ ] 常見漢字 100：只認讀不寫

## 學習功能

- [ ] 筆順動畫（可用 KanjiVG 的開源 SVG 資料）
- [ ] 間隔重複（SRS）：依上次練習時間安排今日複習
- [ ] 跟讀練習：用 Web Speech 的語音辨識（Chrome 支援 `ja-JP`）判斷發音
- [ ] 情境對話模擬：一問一答的小劇場（例：點拉麵全流程）

## 3D／視覺

- [ ] 3D 便利商店：走進店裡，點商品看名稱
- [ ] 假名雨加入「單字模式」（落下菜單單字，輸入中文意思或拼音）
- [ ] 3D 電車車廂：聽廣播，選下一站

## 技術

- [ ] PWA（Service Worker）：離線也能用，可以「加到主畫面」在旅途中使用
- [ ] 進度匯出／匯入（換電腦時備份）
