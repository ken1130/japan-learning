# 日文內容校對

使用者是零基礎，**無法自己發現錯誤**，所以錯的內容會直接被背進去。寧可少放，不要放錯。

## 檢查清單

對每一筆新增／修改的資料逐項確認：

### 讀音（kana）
- [ ] `kana` 是 `jp` 的**完整**讀音，沒有漏字
- [ ] 連濁正確：揚げ出し豆腐 → あげだし**ど**うふ、親子丼 → おやこ**ど**ん
- [ ] 促音、長音正確：切符 きっぷ、ラーメン らーめん
- [ ] 助詞は／を／へ在 `kana` 仍寫原本的假名（は、を、へ），只有 `ro` 改成 wa/o/e
- [ ] 數字讀音：300 さんびゃく、600 ろっぴゃく、800 はっぴゃく、3000 さんぜん、8000 はっせん；4時 よじ、7時 しちじ、9時 くじ

### 羅馬拼音（ro）— 依 `references/romaji-rules.md`
- [ ] shi / chi / tsu / fu / ji
- [ ] 助詞 wa / o / e
- [ ] 長音照假名：ou、ei、ー → 重複母音（kaado、biiru）
- [ ] 促音：kippu、matcha
- [ ] 跟 `kana` 逐音對得上

### 自然度
- [ ] 這是日本人**真的會說**的說法，不是直譯（例：「我要這個」說「これをください」或「これにします」，不說「私はこれが欲しいです」）
- [ ] 旅客說的句子用**禮貌體**（です／ます），不要用常體或過度敬語
- [ ] `hear: true` 的句子是店員實際使用的敬語原句
- [ ] 招牌、菜單用語是日本實際看得到的寫法（漢字 vs 假名）

### 中文
- [ ] 繁體中文、台灣用語（計程車不是出租車、捷運/地鐵、優格不是酸奶）
- [ ] 意思精確，必要時括號補充（例：「お通し：小菜（會收費）」）

## 自動檢查

```bash
python3 .claude/skills/japanese-content-review/check_data.py
```

會檢查：id／jp 是否重複、kana 欄位只含假名、會話 `ro` 欄是否只用 ASCII、`SCENE_SIGNS` 與 `MENUS.parts` 的參照是否存在。
腳本只能抓格式錯誤，**語意正確性仍要人工（或你）逐條看**。

## 不確定時

- 不確定的句子不要加，或在回覆中明確告訴使用者哪幾句不確定。
- 可以查 Jisho.org、Weblio 確認讀音（見 `references/resources.md`）。
